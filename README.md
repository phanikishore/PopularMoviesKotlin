# 🎬 Popular Movies – Android Application

A native Android movie discovery application developed using Kotlin and Android Jetpack components.

The application integrates with a third-party movie data API to retrieve and display popular movies and their detailed information.

## ✨ Features

- **Popular Movies:** Browse and explore popular movie listings.
- **Movie Details:** View detailed information about selected movies.
- **API Integration:** Fetch movie information using Retrofit.
- **Asynchronous Operations:** Handle background operations using Kotlin Coroutines.
- **Navigation:** Navigate between movie listing and details screens.
- **Lifecycle-Aware UI:** Manage observable UI data using LiveData.
- **View Binding:** Interact with UI components using View Binding.

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Kotlin | Programming language |
| Kotlin Coroutines | Asynchronous programming |
| Retrofit | REST API integration |
| LiveData | Observable data management |
| Navigation Component | Screen navigation |
| View Binding | UI component access |
| Android Jetpack | Modern Android development components |

## 🏗️ Architecture

The application uses Android Jetpack components to manage UI data, application navigation, and API communication.
